# Aki Music v0.1.0

首个 Windows 公开版本，基于 YesPlayMusic v0.4.11 二次开发。

## 下载

- `aki-music-0.1.0-setup.exe`：NSIS 安装包（Windows 10/11 x64）
- `aki-music-0.1.0-portable.exe`：免安装版
- `latest.yml`：自动更新元数据

> 本版本**未签名**，Windows SmartScreen 可能提示“未知发布者”。请确认文件来自本仓库 Releases 后继续。

## 功能

- 网易云音乐播放、搜索、歌单/专辑/歌手、每日推荐、私人 FM；
- 三级歌词引擎（AMLL TTML → 网易云逐字 → 网易云行级）；
- Fume 歌词页：单句电影感 / 逐字歌词，可调倾斜、浮动、间距、入场时长、发光；
- 多色动态模糊背景、封面调色板与切歌颜色插值、音频节拍反应；
- 桌面歌词（Windows 11 24H2+ 壁纸层）与远程控制窗口；
- 双人「一起听」，可与官方客户端互通；
- 请求调度 P0–P3、并发去重、取消旧请求、下一首四件套并行预取；
- 音频 Blob URL / Canvas 合成层回收，缓存统计使用元数据表。

## 已知限制

- 桌面歌词壁纸层仅支持 Windows 11 24H2 及以上；
- 本版本未签名，安装时可能出现 SmartScreen 提示；
- 连续高压力切换视觉/歌曲后 GPU 内存会上升到约 300MB（正常空闲约 490MB 私有内存）；
- portable 版不支持自动更新安装，只能跳转 Releases 下载；
- Vue 2.7 已 EOL，Vue 3 迁移计划在后续版本。
