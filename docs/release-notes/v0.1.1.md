# Aki Music v0.1.1

v0.1.0 的图标修复补丁版。

## 修复

- 精简应用图标母图的透明留白，将可见内容放大到画布的 90%；
- 重新生成 16–1024 全尺寸 PNG、Windows ICO 与 macOS ICNS；
- Windows 桌面快捷方式在 32/48px 下图标不再显得偏小。

## 下载

- `aki-music-0.1.1-setup.exe`：NSIS 安装包（Windows 10/11 x64，未签名）
- `aki-music-0.1.1-portable.exe`：免安装版
- `latest.yml`：自动更新元数据

> 本版本仍未签名，Windows SmartScreen 可能提示“未知发布者”。请确认文件来自本仓库 Releases 后继续。

## 说明

- 安装/覆盖安装后，如果桌面快捷方式仍显示旧图标，这是 Windows 图标缓存；重新创建快捷方式或重启资源管理器即可。
- 功能与 v0.1.0 相同，无其它行为变化。
