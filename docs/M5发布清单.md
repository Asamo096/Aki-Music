# M5 发布清单（Windows 首发）

> 日期：2026-11-21
> 基线：tag `m5-baseline`
> 目标：产出一个可安装、可卸载、可检查更新的 Windows 安装包，并完成 AGPL 合规入口。

## 1. 首发范围

- **本轮必做**：Windows 10/11 x64，NSIS 安装包 + portable 包。
- **暂缓**：macOS / Linux 的签名、公证与安装验证；桌面歌词壁纸层只支持 Windows 11 24H2+，其他平台应继续隐藏入口。
- **更新通道**：GitHub Releases（公开仓库 `Asamo096/Aki-Music`）。

## 2. 发布前检查

```bash
git status                       # 必须干净
git tag --list | tail -5         # 确认 m5-baseline / visual-v3-final
pnpm test                        # 216 项
pnpm typecheck
pnpm lint
pnpm build:electron
```

打包版功能回归：

- 登录/登出、搜索、歌单/专辑/歌手页；
- 播放/暂停/拖动/快速连续切歌；
- 歌词三级降级、桌面歌词、远程控制；
- 一起听创建/加入/切歌/进度同步；
- 设置页清缓存、视觉模式切换。

资源验收：

```bash
node scripts/verify-resources.mjs
```

- Canvas 最多 2 个且关闭后全部隐藏；
- 50 次切歌 Blob 创建/撤销数量一致、存活 1；
- 空闲私有内存 < 500MB。

## 3. 构建安装包

版本号在 `package.json` 的 `version` 字段；每次发布必须递增（electron-updater 用它比较版本）。

```bash
# 只构建，不上传
pnpm build:electron
npx electron-builder --config electron-builder.yml --win --publish never
```

产物在 `dist_electron/`：

- `aki-music-<version>-setup.exe`（NSIS 安装包）
- `aki-music-<version>-portable.exe`（portable）
- `latest.yml`（自动更新的元数据）

> NSIS 安装包才能在“关于/更新”路径里替换自身；portable 包只能提示用户去 Releases 下载。

## 4. 发布到 GitHub Releases

需要本机有可推送 Release 的 `GH_TOKEN`：

```bash
GH_TOKEN=... npx electron-builder --config electron-builder.yml --win --publish always
```

发布后在 GitHub Release 中确认：

- 安装包、portable、`latest.yml` 都已上传；
- Release 不是 Draft（Draft 对 electron-updater 不可见）；
- `REPO_URL` / `RELEASES_URL`（`src/config/app.ts`）指向 `https://github.com/Asamo096/Aki-Music`。

## 5. 更新检查验收

1. 安装旧版本（例如 0.1.0），启动应用；
2. 发布一个更高版本（0.1.1）的 Release；
3. 重新启动旧版本：
   - 主进程日志出现 `[background.js] checkForUpdates`；
   - 有新版时弹出「发现新版本 v…」；
   - 点「下载」打开 GitHub Releases 页面。
4. Release 不存在或网络失败时只写日志，不得弹错误轰炸用户。

> 当前策略是“检查 + 提示下载”，不自动静默更新。`autoUpdater.autoDownload = false`。

## 6. 安装/升级/卸载验收

- 干净机器安装：开始菜单、桌面快捷方式、卸载项、应用图标正确；
- 覆盖升级：用户数据（播放器设置、一起听登录态、IndexedDB 缓存）保留；
- 卸载：进程退出、快捷方式移除，不残留桌面歌词窗口；默认**保留**用户数据目录；
- 首次启动：`trackSourceMeta` 迁移完成，缓存统计正确；
- Windows SmartScreen：无签名时会出现提示，发布说明中注明。

## 7. AGPL 合规

- 仓库保持公开，`LICENSE` 随仓库提供；
- 设置页底部已有 `AGPL-3.0` 链接（指向 `REPO_URL/blob/main/LICENSE`）与项目仓库链接；
- `NOTICE.md` 保留 YesPlayMusic 上游版权与改动说明；
- Release 说明里附源码仓库与对应 tag；
- 不打包任何未授权字体/图片/商标资源。

## 8. 已知限制（写入 Release Notes）

- 连续 100 次视觉/切歌压力后 GPU 进程会到约 300MB，总私有内存约 680MB；正常空闲约 490MB；
- 桌面歌词壁纸层仅 Windows 11 24H2+；
- Vue 2.7 已 EOL，Vue 3 迁移留到 M6；
- 远程音源没有频谱反应，走呼吸兜底；
- portable 包不支持自动更新安装，只能跳转下载。

## 9. 回滚

- 若新版本更新检查/安装路径异常：在 GitHub 上将对应 Release 标记为 Pre-release 或删除，重新发一个修复版本；
- electron-updater 只认最新正式 Release，旧版本仍可手动下载；
- 安装包升级失败时，用户可卸载后重装，IndexedDB 用户数据不受安装目录影响。
